# Pano P-2 — main workspace, menus and notifications

Target release: 1.0.0. Runtime version remains 0.5.1 for this intermediate PR.
The branch started from main ee1eee3 after design foundations #11, music #13
and release trigger #14 merged. It was then rebased onto main 8ac3bfd after
Claude's #12 merged, preserving its window/scroll/update changes and native
window-frame test, then onto bd9e4de after extension PR #16 merged. Extension
sources and its browser test remain unchanged from main. The manifest was
regenerated from Git's index.

## Scope and invariants

- P01/P02: responsive tile workspace, live fastest active transfer, next active
  or queued transfer, five-minute aggregate speed history, status summary,
  disk usage/session totals, native download table, queues and categories.
- No active transfer is fabricated from a paused row. The current-card action
  pauses its explicit download ID without changing the list's multi-selection.
- Status segments include active, finished, paused and the existing error view.
  Shared unfinished/error semantics remain available for the other designs.
- TableSurface retains Treeview identity, scroll, keyboard focus, Ctrl/Shift
  multi-selection, double click and context-menu behavior. The dedicated row
  action cell opens that same context menu and retains an existing selection.
  Selecting rows reveals the action toolbar in the scroll viewport; keyboard
  focus also reveals its target without changing the selection or focus owner.
- `pano_visible_columns` keeps Pano's default name/progress/size/status columns
  separate from Atlas's `visible_columns`. The action column is presentation
  only; it is not saved as a data-column preference. Filename stays mandatory.
- P18/P19: existing PopupMenu and Toast lifecycle/keyboard/grab/action code is
  reused with Pano's grouped pale container, rounded rows, radio/danger styles
  and white notification card. Timers, pause/resume, bounded stacking and
  explicit action callbacks remain unchanged.
- Shared Panel and SpeedChart own the tile appearance and filled area graph.
  Bounded, cached shadow images are copied before use. Atlas/Odak retain their
  existing appearance; Yörünge keeps square corners, including explicit-radius
  callers. Existing font measurement/scaling and ascender-based text remain.
- URL paste remains search, as approved. Clipboard/drop New download actions
  remain explicit. Tools, HUD, settings, capture, speed limits, queues, column
  choices and destructive actions still call the existing application methods.

No database/engine/music/extension or Claude-owned dialog module is changed.
No real profile or installed application is used. Source/portable publication
and the final version bump belong to the separate 1.0.0 release step.

## Visual comparison and limits

P01/P02/P18/P19 references come from the approved Pano package. Real native
previews cover 1440x900 main/empty/selection, 1080x640 compact, the actual row
context menu and an actionable toast. Wide tiles use four columns; compact
tiles use two and allow vertical scrolling. Hidden columns leave the uniform
group so the hero and list use the full compact width.

Text uses the repository's approved 1.15 scale. Rows retain the existing
54 logical-pixel size for that typography rather than the mockup's 46 px.
The error status segment and Tools/HUD shortcuts are retained additions; the
search placeholder reflects the approved search-only URL behavior. Live data,
paths and available actions naturally differ from mockup fixtures. Menu rows
join into white rounded groups within the pale container, preserving the
shared popup's keyboard and modal-grab ownership without nested menu widgets.

P03–P17 dialogs/settings/HUD and P19 message dialogs follow in P-3/P-4. They
are not claimed complete by this PR. Yörünge's main layout follows in Y-2.

## Proof

`test_pano_view` covers live task precedence, fastest selection, queued next
item, unknown progress, display language, distinct summary filters, bounded
shadow/copy isolation and independent persistent column choices.
`test_ui_pano.py` exercises actual disposable-profile windows and input events,
including a row-menu click, URL filtering, card targets, selection actions,
queue start, pause/error filters, persisted columns, menu/radio/danger, toast
timers/action dispatch, stable images and full-width compact tiles.

The source/geometry report rejects missing previews, changed source hashes,
changed PNG bytes, invalid dimensions/palettes and centre/baseline drift over
1.5 px. Counter-anchor and compact-grid faults were separately restored only
in a temporary copy: both assertions failed, and the corrected code passed.
The current source is tested again after integration/rebase.

Local files stay in ignored build output; GitHub summary contains hashes and
measurements, not stored artifacts. Both Verify and release workflows include
the Pano unit/UI/report gates. Merge remains the user's action.
